# Contributing

Contributions should preserve the skill's local-only workflow, preview-first contract, registry authority, and Chinese patent-writing focus.

1. Read the nearest `AGENTS.md` and the skill `SKILL.md` before changing files.
2. Keep runtime cases and generated outputs in the governed workspace paths.
3. When changing Python or scripts, use the matching readable skill gates before editing and run their post-generation checks.
4. Update the relevant registry source and documentation together; do not hand-edit the derived SQLite registry.
5. Describe the validation commands and any skipped remote checks in the pull request.

Do not include confidential patent material, customer data, or private research notes in commits, fixtures, screenshots, or issue reports.
