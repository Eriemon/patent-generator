# Security

Readable Patent Generator is designed for local, controlled work folders. Do not place confidential case material in public issue text, pull requests, or generated examples.

If you discover a security or privacy problem in the skill, contact the maintainers through the private repository access path and include:

- the affected release version;
- a minimal reproduction that does not contain confidential material;
- the local workflow boundary where the problem appears; and
- any suggested containment or recovery step.

Please allow maintainers to acknowledge and assess the report before public disclosure.
