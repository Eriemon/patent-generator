# 端到端流程

## 目标
- 在本地工作区中，把研究材料逐步收敛成可审阅的中文专利草稿与配套治理工件。

## 正式顺序
1. 建案并固定 `case_dir`
2. 材料盘点与必要的 Office/PDF 转换
3. facts 抽取与候选创新点整理
4. 主案选择与查新规划
5. 生成 `pre_draft_preview.md`
6. 人工确认预览
7. 生成正文、附图、权利要求、自检报告和可选导出

## 硬门
- 未确认预览时，正式 `run_pipeline` 必须停在 `preview_pending`。
- 只有在 `preview_status.json` 明确确认后，才允许进入正文、附图、权利要求、自检和导出阶段。
